# 《诡秘之主》占卜黄牌流 GVG／6V6 攻略

> 本攻略主要分享占卜黄牌流在常规 GVG 和 6V6 对战中的属性、技能及封印物搭配，并补充一些实战操作细节。配置只是基础，站位、技能节奏和队友配合才是决定实战上限的关键。

## 一、属性选择

### 输出属性

推荐优先级：

1. 穿刺
2. 攻击
3. 暴击
4. 技能增强

穿刺是黄牌流最重要的输出属性，建议优先堆叠。攻击、暴击和技能增强则用于进一步提高技能伤害与爆发能力。

### 防御属性

推荐优先级：

1. 格挡
2. 防御
3. 抗暴
4. 技能抵挡

占卜需要保持安全距离持续输出，但也要具备应对突进和突然转火的能力。防御属性中优先选择格挡，衣服和鞋子的格挡属性越高越好。

---

## 二、GVG 常规团战：黄牌流

### 技能配置

- 纸牌飞刀
- 奇迹牌雨
- 卡牌大师
- 火焰跳跃

火焰跳跃可以提供位移和保命能力，明显提高团战容错。如果自身生存压力不大，想进一步补充伤害，也可以将火焰跳跃替换为 **塔罗牌阵**。

### 封印物推荐

| 位置 | 推荐选择 | 搭配说明 |
| --- | --- | --- |
| 1号位 | 面具 / 四叶草 | 常规可以选择面具；如果暴击面板偏低，推荐使用四叶草补足暴击 |
| 2号位 | 纸人 / 钱包 | 钱包偏综合收益；纸人更注重生存和容错。纸人触发并进入冷却后，可以脱战更换钱包 |
| 3号位 | 神灯 | GVG 中表现稳定，推荐优先携带 |

### 密偶推荐

推荐从以下密偶中选择：

- 夫人
- 星象
- 守秘
- 剥面人

密偶选择不必过于固定，优先上阵等级更高、提供有效属性更多的密偶。核心思路是选择对自身输出或生存有帮助的属性，例如：

- 伤害加深
- 途径专攻
- 伤害减免
- 途径专防御

只要属性对自己有效，就可以在同类型密偶中优先选择等级最高的上阵。

### 人脉技能

推荐携带：**梦魇冲剂**。

GVG 中的击杀通常不会完全取决于单个人脉技能，因此不必强行固定搭配。可以结合自己的人脉技能等级，优先选择等级较高、能够稳定补充伤害或团队收益的技能。

### 密偶技能

推荐选择：

- 牌雨
- 惩戒

两者都属于高范围伤害技能，实战中可以直接选择等级更高的携带。

### 属性建议

- **穿刺：**核心输出属性，建议尽量接近 **3000**。
- **格挡：**核心防御属性，衣服和鞋子上的格挡越高越好。

穿刺决定输出效率，格挡则能提高被敌方突进或远程技能命中后的生存能力。两项属性都需要兼顾，不建议只追求伤害而完全放弃防御。

### 实战技巧

1. 始终保持在战场边缘输出，不要主动进入双方大团中心。
2. 注意敌方战士的位置，避免被拉入敌方人群后集火击杀。
3. 血量较低时，灵活使用火焰跳跃回到己方大团，及时接受治疗。
4. 奇迹牌雨和密偶范围技能尽量覆盖敌方人群密集的位置，提高整体伤害收益。
5. 没有火焰跳跃等自保手段时，站位需要更加谨慎，避免成为敌方的转火目标。

## 三、6V6 对战：黄牌流

### 技能配置

- 纸牌飞刀
- 奇迹牌雨
- 卡牌大师
- 火焰跳跃

这套配置兼顾单点输出、范围伤害和位移保命，比较适合 6V6 的小规模对战环境。

### 封印物推荐

| 位置 | 推荐选择 | 搭配说明 |
| --- | --- | --- |
| 1号位 | 斧头 / 四叶草 | 斧头可以提升操作手感和技能衔接流畅度；四叶草用于补充暴击 |
| 2号位 | 纸人 | 占卜通常不会主动进入大团承伤，钱包收益相对有限；纸人可以防止没有解控时被突然转火秒杀 |
| 3号位 | 神灯 | 提供稳定收益，推荐携带 |

### 人脉技能

推荐携带：**梦魇冲剂**。

使用前应提前与队友沟通，合理利用梦魇冲剂的减疗效果，配合队友对关键目标进行定点击杀。不要在队友无法跟进时随意交出，避免浪费关键技能。

### 密偶技能

推荐携带：**隐身**。

隐身能够提高自身容错。如果对局生存压力不大，也可以主动使用火焰跳跃进场，开启隐身补充伤害，再利用火焰跳跃的第二段及时撤离。

这套操作需要注意敌方控制技能和自身撤退路线，不建议在没有后续自保手段时强行进场。

### 输出循环

推荐的基础输出顺序：

1. 开局直接使用卡牌大师，开始积攒能量。
2. 使用纸牌飞刀起手，提高自身穿刺命中率。
3. 能量叠满后，打出满能量的卡牌大师，完成主要爆发。
4. 根据敌方站位衔接奇迹牌雨，补充范围伤害。

### 实战技巧

1. 开局尽早使用卡牌大师，快速积攒能量，为后续爆发做准备。
2. 纸牌飞刀尽量作为起手技能，先获得穿刺命中率加成，再打出主要伤害。
3. 火焰跳跃、自身解控和密偶隐身不要在同一时间全部交出，确保手中始终保留至少一种自保资源。
4. 时刻保持在战场边缘，盯住一个关键目标进行单点输出。
5. 在保证自己不承受过多伤害的前提下持续压低目标血线，并配合队友完成击杀。
6. 如果使用火焰跳跃进场打伤害，要提前规划第二段位移的撤离位置。

## 四、两种场景的核心区别

| 场景 | 核心思路 | 操作重点 |
| --- | --- | --- |
| 大规模 GVG | 稳住距离、持续制造范围伤害 | 保持战场边缘站位，防止被战士拉进大团中心 |
| 6V6 | 配合队友集火关键目标 | 管理能量与自保技能，利用梦魇冲剂完成定点击杀 |

## 五、总结

大规模 GVG 要稳住距离、持续消耗；6V6 则更加看重沟通、集火和进场时机。

黄牌流的输出并不只取决于面板和装备。合理使用纸牌飞刀的穿刺命中率加成，掌握卡牌大师的能量节奏，并确保火焰跳跃、解控和隐身不会同时进入真空期，才能稳定打出伤害。

> 配置决定下限，站位决定生存，技能释放节奏与团队配合决定上限。
