## 应用里还要开三项

1. **建自建应用。** 应用管理 → 应用 → 自建 → 创建应用。名称随意，例如「活动签到」。可见范围先选会参加活动的部门或成员，范围外的人收不到卡片，也识别不了身份。

2. **可信域名。** 进入该应用 → 网页授权及 JS-SDK → 设置可信域名。只填主机名，例如 `checkin.example.com`，不要写 `https://`。按页面下载校验文件，放到这个网站根目录，保证 `https://checkin.example.com/WW_verify_xxxx.txt` 能打开，再点确定。域名须已备案，备案主体与企业微信主体一致或有关联。

3. **企业可信 IP。** 同一应用底部 → 企业可信 IP。填**调用企业微信接口的那台服务器的公网出口 IP**。公司网络出口变了要改这里，否则发消息和换身份都会被拒绝。这是服务器 IP，不是成员手机 IP。

点卡片这条链路不用配「企业微信授权登录」的扫码回调，也不用通讯录同步 Secret。身份用网页授权的静默授权即可，只能拿到成员 userid。

## 域名要同时打开页面和接口

`WEB_ORIGIN` 必须就是上面的可信域名，并且用 HTTPS。卡片地址是 `https://checkin.example.com/a/活动id`，授权回调是 `https://checkin.example.com/api/v1/wecom/oauth/callback`。两处要在同一主机上，前面用反向代理把页面和 `/api` 转到现有的 Web 与 NestJS。`localhost` 不能设成可信域名，本地代理完不成这四条真机用例。
