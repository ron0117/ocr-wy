# 需求梳理 · 人员列表

源需求要在已有人员列表上补手工增删改，用来纠正 OCR 识别失败或漏行。本版只梳理范围、用例和验收，不涉及实现。

已有能力保持不变：俱乐部筛选、玩家名称关键字、九列展示、表头排序、导入写入，以及排名 / 非凡评分相对上次导入的升降。本需求只加「新增、修改、删除」。

## 产品定位

人员列表仍是查看俱乐部成员的页面。识别错了或漏了的行，由登录用户在这一页改正确，不必再传一张图。

手工改的是当前这一行的展示值。它不代替导入，也不重算别人的排名。

## 用户与用例

使用人是已登录的后台操作者。只能动自己俱乐部下的人员。

| ID | 优先级 | 用例 | 验收要点 |
|---|---|---|---|
| UC-01 | Must | 手工新增人员 | 选定俱乐部后填写玩家；保存后出现在该俱乐部的人员列表中 |
| UC-02 | Must | 修改已有人员 | 可改正玩家名称、排名、等级、途径、非凡评分、风尚度、周活跃、入会时间，以及所属俱乐部 |
| UC-03 | Must | 删除人员 | 确认后该行从列表消失；同俱乐部其他人不受影响 |
| UC-04 | Must | 纠正后仍可筛选和排序 | 增删改之后，俱乐部下拉、玩家名称关键字、表头排序与改前行为一致 |
| UC-05 | Must | 手改也算一次更新 | 保存时把改前的排名、评分记为上次；箭头相对这次改前的值。新增的人没有上次值，不显示箭头 |

## 功能拆解

操作放在现有人员列表页，交互对齐「创建俱乐部」：页头「新增」，表格增加「编辑」「删除」。编辑和新增用对话框，删除前确认。

### 字段

| 字段 | 新增 | 修改 | 规则 |
|---|---|---|---|
| 所属俱乐部 | 必填 | 可改 | 只能选当前用户的俱乐部 |
| 玩家名称 | 必填 | 可改 | 去首尾空格后不能为空；同一俱乐部下不可重复 |
| 排名 | 必填 | 可改 | 正整数；不按评分重算，也不改其他玩家的排名 |
| 等级 | 可空 | 可改 | 空则存空；有值时为正整数 |
| 途径 | 可空 | 可改 | 文本 |
| 非凡评分 | 可空 | 可改 | 空则存空；有值时为整数 |
| 风尚度 | 可空 | 可改 | 空则存空；有值时为整数 |
| 周活跃 | 可空 | 可改 | 空则存空；有值时为整数 |
| 入会时间 | 可空 | 可改 | 保留原文，如「26天」，不换算成日期 |

俱乐部名称仍由所属俱乐部带出，不单独填写。

### 与导入、升降的关系

导入逻辑不变：再次导入时，仍按「俱乐部 + 玩家名称」覆盖当前值，并把覆盖前的排名、评分留作比较。

手工新增：没有上次排名、上次评分，列表不显示升降箭头。

手工修改：先把当前排名、评分抄到上次字段，再写入新值，并刷新该行的数据更新时间。把识别错的「5」改成「3」时，箭头相对这次改前的 5。排名或评分没有变化时差值为 0，不显示箭头；因此只改正其他列时，原先相对导入的箭头会消失，这次保存成为新的比较基准。

本次导入没出现、也没被手删的玩家，保持不动。

### 删除

删除前确认。确认后只删除这一行。导入批次和原图保留。该俱乐部因此没有人员时，俱乐部仍在，之后可以按原规则删除俱乐部。

## 非功能需求

| 项 | 要求 |
|---|---|
| 界面 | 继续使用浅蓝色 Element Plus；列表仍是 `el-table` |
| 归属 | 不能查看、新增、修改、删除别人的人员；目标俱乐部也必须属于当前用户 |
| 冲突 | 同一俱乐部已有同名玩家时拒绝保存，并说明名称重复 |
| 失败 | 保存或删除失败时，列表里的其他行保持原样 |

## 端到端流程

1. 打开人员列表，点「新增」，选择俱乐部，填写玩家名称和排名，其余可留空，保存。
2. 用俱乐部或玩家名称找到该行，确认九列与所填一致，且排名、评分没有箭头。
3. 对一条导入来的人员点「编辑」，改正识别错的列，保存。筛选和排序仍然可用。
4. 改正排名或评分后，箭头按新值与保存前的值比较。只改其他列时，排名和评分与保存前相同，不显示箭头。
5. 点「删除」并确认，该行消失，其他人员还在。

## 范围

**In**

- 人员列表上的新增、修改、删除
- 九个已有展示列中，除俱乐部名称外都可在表单里填写；俱乐部用下拉选择
- 同俱乐部玩家名称唯一
- 手工修改刷新该行数据更新时间，并把改前的排名、评分记为上次

**Out**

- 职位、分组、当前状态
- 批量导入以外的图片上传、重新 OCR
- 按评分重算排名，或删除一人后自动调整其他人的排名
- 玩家改名后与旧名称合并为同一人
- 删除导入批次或原图
- 人员变更历史页

## 待澄清

| ID | 问题 | 不答复时的暂定 |
|---|---|---|
| Q1 | 手工改正排名或评分后，箭头相对哪一次？ | 已确认：手改记成一次更新。保存前的排名、评分写入上次字段，箭头相对改前的值。新增人员上次值为空，不显示箭头 |
| Q2 | 编辑时能否更换俱乐部、修改玩家名称？ | 可以。换俱乐部或改名后仍要求目标俱乐部内名称唯一 |
| Q3 | 排名以外的数字列是否必填？ | 只有俱乐部、玩家名称、排名必填，其余可空 |
| Q4 | 删除是否允许恢复？ | 确认后直接删除，不提供回收站 |

## 验收标准

1. 人员列表可以新增一名指定俱乐部的玩家；玩家名称或排名为空不能保存。
2. 同一俱乐部再新增同名玩家时保存失败，原记录不变。
3. 编辑一条人员后，列表显示改正后的列；数据更新时间变为这次保存的时间。
4. 编辑排名或评分后，箭头按新值与保存前的值比较。只改其他列时，排名和评分与保存前相同，不显示箭头。
5. 手工新增的人员不显示排名箭头和评分箭头。
6. 删除确认后该行消失，同列表中的其他人员仍在；取消删除则行还在。
7. 增删改之后，俱乐部筛选、玩家名称搜索、表头排序仍按原规则工作。
8. 使用别人的俱乐部或人员 id 时不能成功。
